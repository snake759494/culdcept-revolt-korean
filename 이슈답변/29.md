## DLC 8건은 v2.22 에 들어가 있습니다. `암드` 만 이번에 고쳤습니다

### 이미 들어가 있던 것 (v2.22, 배포물에서 실측 확인)

zip 안의 DLC 패치를 원본 DLC 에 직접 얹어 풀어서 확인했습니다.

| 지적하신 것 | 지금 값 |
|---|---|
| `{N}과 직접 싸워서` | `{N}와 직접 싸워서` |
| `{N}과 한 팀만 아니라면` | `{N}와 한 팀만 아니라면` |
| `사이크이 쫓아와도` | `사이크가 쫓아와도` |
| `유마이 쫓아와도` | (같은 한 줄입니다 — 이름만 바뀝니다) |
| 테넷트 대사 뒤 빈 대화창 | 3줄에 들어갑니다(칸 17/17/16) |
| 존크스 가운뎃줄 공백 | 19/18/18 로 세 줄이 다 찹니다 |
| `4겁` | `4등` |
| `1쟁 1쐴` | `1전 1승` |

`4겁`·`쟁`·`쐴` 이 안 잡히던 이유는 이렇습니다. 한글을 폰트의 한자 슬롯에 얹어
쓰기 때문에, **번역이 안 된 한자는 엉뚱한 한글로 그려집니다**(位→겁, 戦→쟁,
勝→쐴). 화면 글자로 검색하면 절대 안 나옵니다.

### `암드` → `아머드` — 여기서 막혀 있었습니다

이것만 아직 화면에 그대로였습니다. 게임 업데이트(ver 1.2)를 깔면 카드 이름은
`CULDCEPT.DAT` 이 아니라 **업데이트 실행코드**에서 읽히는데, 저희가 배포해 온
실행코드가 **v2.17 무렵 번역으로 굳어 있었습니다.** `암드 팔라딘`,
`아무드 프린세스`, `스타추`, `자폭 시`, `니케` 가 그대로 남아 있었습니다.

**v2.26 에서 실행코드를 지금 데이터로 다시 만들었습니다.** 13곳이 전부 맞게
들어간 것을 확인했습니다.

### 한 가지 미리 알려 드립니다 — `와/과` 는 고정입니다

이름이 들어가는 자리 뒤의 조사는 **글자로 박혀 있어서 이름 받침에 따라 바뀌지
않습니다.** 이름 뒤에 조사가 붙는 자리가 본편 921곳, DLC 15곳입니다. 지금은
받침 없는 이름(로아·유마·사이크)에 맞춰 두었으니, 받침 있는 이름을 쓰시면 같은
어색함이 반대로 나옵니다. 조사 없는 표현으로 바꿔 나갈지 알려 주시면 그렇게
하겠습니다.
