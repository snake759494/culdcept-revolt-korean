## 28건 중 27건을 고쳤습니다. 못 한 하나와 그 이유도 적습니다

스크린샷을 한 장씩 다시 열어 요청을 세었더니 **28건**이었습니다. v2.25 까지 14건을
고쳤고, **v2.26 에서 13건**을 마저 했습니다. 못 한 것은 하나입니다.

### v2.22 ~ v2.25 에서 이미 고친 것

`{N}과`→`{N}와`(2곳) · `있어`→`있지` · `가야 해요`→`가야해` · `겐`→`겐의` ·
`중요한 게`→`중요한 것` · `말라앗`→`말아앗` · `…네?`→`…뭐?` ·
`아,`→`뭐,` / `않을 거다`→`않을 거야` · `네 따위`→`너 따위` · `네 대신`→`널 대신` ·
빈 대화창 2곳 · 마침표만 찍힌 대화창 1곳

### v2.26 에서 고친 것

| 지적하신 것 | 고친 결과 |
|---|---|
| 둘째 줄이 `꼭` 한 글자뿐 | `꼭 {N}을 만나고` 까지 둘째 줄로 올림 |
| `나왔/어.` 로 갈라짐 | `도시 생활을 동경해서` / `시골 마을에서 나왔어.` 로 나눔 |
| 유마 대사 한 칸이 `え？` 그대로 | `에？` |
| 존크스 대사 한 칸이 일본어(깨진 한글로 보임) | `그 뒤엔 다시, 내 세상이닷!` |
| `백작……앞잡이냐?` | `백작의…앞잡이냐?` |
| `들어온 게` / `네놈` | `들어오다니` / `네놈은` |
| `놈들과는다른것같군` | `놈들과는 다른 것 같군` |
| `백작님의부하가되지않을래?` | `백작님의 부하가 안 될래?` |
| `가능하면유용하게쓰고싶거든.` | `되도록 유용하게 쓰고 싶어.` |
| `꾐에` | `권유` |
| `들 성싶나` | `들 것 같나` |
| `{N}이 도와줬어` / `{N}이라면` | `{N}가` / `{N}라면` |

낱말이 들러붙던 세 곳은 **문장이 자리보다 길어서** 빌더가 뒤에서부터 공백을 지운
것이었습니다. 자리를 늘릴 수가 없어(원문 페이지의 바이트 수가 고정입니다) 뜻을
유지하면서 문장을 몇 글자 줄여 공백을 되살렸습니다. 그래서 `되지 않을래?` 가
`안 될래?` 로, `가능하면` 이 `되도록` 으로 바뀐 것이니 양해 부탁드립니다.

### 못 한 것 하나

**`근데!` → `하지만!`** 은 못 넣었습니다. 그 대사 자리가 **6바이트**인데
`하지만！` 은 8바이트라 2바이트를 넘깁니다. 같은 이벤트에 페이지가 하나뿐이라
다른 데서 자리를 빌려올 수도 없습니다. 두 글자짜리 대안(`한데!` 처럼)을 하나
골라 주시면 그대로 넣겠습니다. 아니면 그냥 두겠습니다.

### 스티커 두 장

`할수있어요!` 와 `빨리 빨리` 는 게임 화면이 아니라 스티커·짤이라 대응하는 데이터가
없습니다. 재촉으로 알아듣고 이번엔 이슈에 올라온 것을 한꺼번에 처리했습니다.
