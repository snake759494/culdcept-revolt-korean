컬드셉트 리볼트 한글 패치 v2.9 설치 안내
===========================================

이 패키지는 게임 원본이나 DLC 본체를 포함하지 않습니다.
본인이 소유한 일본판 Rev 2 게임에서 CULDCEPT.DAT를 추출해야 합니다.

[본편 설치]

1. DeltaPatcher를 실행합니다.
2. Original에 본인이 추출한 CULDCEPT.DAT를 지정합니다.
3. Patch에 이 폴더의 culdcept-korean.xdelta를 지정하고 적용합니다.
4. 결과 파일 이름을 CULDCEPT.DAT로 맞춰 다음 경로에 둡니다.

   <Azahar 사용자 폴더>\load\mods\00040000000F5700\romfs\CULDCEPT.DAT

[DLC 설치]

1. 이 패키지의 load 폴더를 Azahar 사용자 폴더에 폴더째 병합합니다.
2. 기존 v2.4/v2.6 파일이 있으면 덮어쓰기를 허용합니다.
3. 다음 파일과 폴더가 있어야 합니다.

   load\mods\0004008c000f5700\romfs\ContentInfoArchive_JPN_ja.bin
   load\mods\0004008c000f5700\romfs_ext\*.ips  (108개)

DLC 패치는 DLC 본체를 설치하지 않습니다. 본인 소유 DLC가 Azahar 가상 SD에 이미
설치되어 있어야 합니다. DLC를 보유하지 않은 경우에도 본편 패치는 정상 동작합니다.

[재실행]

Azahar와 게임을 완전히 종료한 뒤 게임을 새로 부팅합니다. 기존 세이브 상태를 곧바로
불러오지 마세요.

[검증]

verify_install.cmd를 더블클릭하면 기본 %APPDATA%\Azahar 설치 경로와 로그를 읽기
전용으로 검사합니다.

Python이 있으면 원본과 실제 게임이 읽는 패치본을 다음처럼 전수 대조할 수 있습니다.

python verify_cards.py "원본\CULDCEPT.DAT" ^
  "%APPDATA%\Azahar\load\mods\00040000000F5700\romfs\CULDCEPT.DAT"

정상 결과는 크리처 241/241, 아이템 75/75, 스펠 133/133, 미번역 일본어 필드 0개,
널 구분 오프셋 14,282개 동일입니다.
