# v2.9 — 본편·DLC 통합 배포와 카드 449장 전수 검증

v2.9는 본편과 DLC 패치를 따로 찾아 설치하면서 생기던 혼선을 없앤 통합 배포본이다.
새 게임 데이터나 원본 파일을 포함하지 않으며, 검증된 기존 차이 패치를 한 패키지에
모은다.

## 포함 내용

- 본편 v2.2 `culdcept-korean.xdelta`
- DLC v2.8 카탈로그와 안전한 직접 리소스 IPS 108개
- `verify_cards.py`: 수집 카드 449장 전수 검증
- `verify_patch.py`: 본편 대표 적용 지점 검증
- `verify_install.py` / `verify_install.cmd`: Azahar 경로·DLC·로그 진단
- 설치 안내문과 카드 전수 검수 보고서

## 이번에 바로잡은 점

- DLC ZIP만 설치하면 본편 카드 DB가 바뀌지 않는다는 점을 설치 첫 단계에 명확히 했다.
- 과거의 “DLC 또는 0x0d/0x8d에 다른 카드 사본이 있다”는 추정을 폐기했다.
- 제공 스프레드시트 449행과 본편 카드 DB를 영문 식별자로 1:1 대조했다.
- 원본·패치본의 카드 표시 이름·능력·플레이버·용어·전략을 전수 비교하는 자동 검증기를
  추가했다.

## 검증 결과

- 크리처 241/241, 아이템 75/75, 스펠 133/133
- 표시 이름 449/449, 능력 423/423, 플레이버 449/449, 용어 292/292,
  전략 449/449 변경
- 미번역 일본어 필드 0개
- 한글 코드 없는 번역 대상 필드 0개
- 원본·패치본 엔트리 1190 널 구분 오프셋 14,282개 전부 동일
- DLC 직접 리소스 108개에서 `0x2B` 이후 보호 헤더 변경 0개
- 자동 테스트 18개 통과
- Azahar 2125.1.3에서 LayeredFS 본편 교체 로그와 게임 부팅 확인

세부 카드 검수는 [`CARD_AUDIT.md`](CARD_AUDIT.md), DLC 프리징의 정확한 원인과 수정은
[`RELEASE_V2_8.md`](RELEASE_V2_8.md)에 기록했다.

## 설치

1. `culdcept-korean-complete-v2.9.zip`을 새 폴더에 푼다.
2. `culdcept-korean.xdelta`를 본인이 추출한 일본판 Rev 2 `CULDCEPT.DAT`에 적용한다.
3. 결과 파일을 `load/mods/00040000000F5700/romfs/CULDCEPT.DAT`에 둔다.
4. ZIP의 `load` 폴더를 Azahar 사용자 폴더에 병합해 DLC 카탈로그와 IPS 108개를
   덮어쓴다.
5. Azahar를 완전히 종료한 뒤 게임을 새로 부팅한다.

본인 소유 DLC가 설치되어 있지 않으면 DLC 오버레이는 적용할 원본 리소스를 찾지 못하지만,
본편 패치 실행에는 영향을 주지 않는다.
