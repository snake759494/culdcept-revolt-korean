# 카드 449장 전수 검수 보고서

검수일: 2026-08-29

## 결론

수집 카드 **449장 전부**가 본편 `CULDCEPT.DAT` 엔트리 1190에 존재하며, 현재 한글
패치본에서는 카드별 번역 대상 필드가 모두 바뀌어 있다.

| 종류 | 스프레드시트 | 게임 DB | 번역 적용 |
|---|---:|---:|---:|
| 크리처 | 241 | 241 | 241 |
| 아이템 | 75 | 75 | 75 |
| 스펠 | 133 | 133 | 133 |
| **합계** | **449** | **449** | **449** |

- 미번역 일본어 필드: **0개**
- 번역 대상인데 고정 완성형 한글 코드가 없는 필드: **0개**
- 카드명 레코드 배치 이상: **0개**
- 원본·패치본 널 구분 오프셋 불일치: **0개**

## 1. 스프레드시트 검수

제공된 BIFF `.xls`의 `Creatures`, `Items`, `Spells` 시트를 직접 파싱했다.

- 행 수: 241 + 75 + 133 = 449
- 빈 영문 식별자: 0
- 빈 대상 텍스트: 0
- 중복 영문 식별자: 0

스프레드시트 영문명에는 철자 오류가 3개 있었으며, 게임 DB의 가까운 고유 식별자와
다음처럼 대응한다.

| 스프레드시트 | 게임 DB |
|---|---|
| `Cimera` | `Chimera` |
| `Could Gizmo` | `Cloud Gizmo` |
| `Turqoise Amulet` | `Turquoise Amulet` |

세 오타를 정규화한 뒤 449개 행이 게임 DB의 449개 고유 카드 레코드에 빠짐없이 1:1로
대응했다. 누락이나 중복 대응은 없다.

## 2. 게임 카드 DB 식별 방법

엔트리 1190을 해제해 널 종료 세그먼트로 나누고, 다음 구조를 만족하는 레코드를 찾았다.

```text
[-2 표시 이름] [-1 능력] [0 영문 이름] [+1 플레이버] [+2 용어] [+3 전략]
```

구조상 카드형 레코드는 489개다. 이 중 같은 영문 이름이 반복되는 변신용 내부 레코드
40개를 제외하면 고유 수집 카드가 정확히 449개 남는다. 순서는 크리처 241장, 아이템
75장, 스펠 133장이다. 실제 카드 화면의 데이터는 이 본편 엔트리에서 읽으며, DLC나
0x0d/0x8d 엔트리에 별도 카드 사본은 없다.

## 3. 필드별 원본·패치본 전수 대조

일본어 글자가 들어 있던 원본 필드를 카드마다 같은 세그먼트의 패치본과 바이트 단위로
비교했다.

| 필드 | 일본어 원문 필드 | 변경됨 | 미변경 |
|---|---:|---:|---:|
| 표시 이름 | 449 | 449 | 0 |
| 능력 | 423 | 423 | 0 |
| 플레이버 | 449 | 449 | 0 |
| 용어 | 292 | 292 | 0 |
| 전략 | 449 | 449 | 0 |

검사 대상 필드에서 실제로 달라진 바이트는 130,369바이트다. 일본어 원문이 있던 모든
필드가 바뀌었고, 각 결과에 패치 폰트의 고정 완성형 한글 코드가 들어 있다. 영문 식별자
449개는 그대로 보존됐다.

또한 원본과 패치본 엔트리 1190의 크기는 253,634바이트로 같고, 널 구분 오프셋
14,282개가 전부 동일하다. 번역 때문에 빈 세그먼트가 추가돼 뒤 카드의 필드가 밀린
과거 v1.9 계열 회귀도 없다.

## 4. 재현 명령

본인이 추출한 원본과 실제 게임이 읽는 패치본을 지정한다.

```bash
python verify_cards.py 원본/CULDCEPT.DAT \
    Azahar/load/mods/00040000000F5700/romfs/CULDCEPT.DAT
```

검증기는 카드 목록이나 일본어 원문을 내장하지 않는다. 영문 식별자와 레코드 구조로
449장을 동적으로 찾고, 필드 변경·한글 코드·영문 식별자·널 오프셋을 검사한다. 하나라도
누락되거나 구조가 달라지면 종료 코드 1을 반환한다.

실행 확인에서는 Azahar 2125.1.3 로그의
`LayeredFS replacement file in use for /CULDCEPT.DAT`를 확인했고, 같은 패치본으로
게임 타이틀까지 정상 부팅했다.
