# v2.6 — DLC 직접 리소스 전체 패키지

이 릴리즈는 이슈 #11에서 확인된 “v2.5로 부팅은 되지만 DLC 화면이 그대로”인 문제를
해결합니다.

- v2.5의 카탈로그 패치에 더해 DLC 직접 리소스 제목 IPS 108개를 포함합니다.
- 다이스·맵·퀘스트·북·책 표지·아바타 화면이 읽는 `.dld`·`.dlm`·`.dlq`·`.dlb`·`.dlj`·`.dla`
  헤더를 모두 패치합니다.
- 원본 DLC와 본편 게임 데이터는 포함하지 않습니다. 본인 소유 DLC가 Azahar 가상 SD에
  설치되어 있어야 합니다.
- 카드 설명은 DLC가 아니라 본편 `CULDCEPT.DAT`의 카드 DB에서 읽으므로, 본편 v2.2
  패치도 함께 적용해야 합니다.

## 적용

1. 기존 v2.4/v2.5 DLC 모드 폴더를 삭제하지 말고 다른 곳으로 옮겨 둡니다.
2. ZIP을 풀고 안의 `load` 폴더를 `%APPDATA%\Azahar\`에 폴더째 병합합니다.
3. 본편 파일이 `load\mods\00040000000F5700\romfs\CULDCEPT.DAT`, DLC 파일이
   `load\mods\0004008c000f5700\romfs` 및 `romfs_ext`에 있는지 확인합니다.
4. Azahar와 게임을 완전히 종료한 뒤 다시 실행합니다.
5. 저장소의 `verify_install.cmd`를 더블클릭해 경로를 읽기 전용으로 확인할 수 있습니다.

## 검증

첨부된 본인 소유 DLC 덤프에서 카탈로그 108/108, 직접 리소스 IPS 108/108 재현 검증을
통과했습니다.
