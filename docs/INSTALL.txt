컬드셉트 리볼트 한글 패치 설치 안내 (v2.11)
===========================================

이 패키지에는 게임 원본도, DLC 본체도 들어 있지 않습니다.
본인이 소유한 일본판(Rev 2)에서 추출한 CULDCEPT.DAT 이 필요합니다.


■ 설치 (2단계)

  1) 본편 패치 만들기 (한 번만)

     DeltaPatcher 에서
       Original : 본인이 추출한 CULDCEPT.DAT
       Patch    : 이 폴더의 culdcept-korean.xdelta

     적용 결과를 아래 경로에 CULDCEPT.DAT 이름으로 둡니다.

       <Azahar 사용자 폴더>\load\mods\00040000000F5700\romfs\CULDCEPT.DAT

  2) 설치.cmd 를 더블클릭

     - DLC 오버레이를 알맞은 자리에 복사합니다
     - 예전 패치가 본편 폴더에 흘려놓은 DLC 파일을 자동으로 치웁니다
     - 설치 상태를 항목별로 검사해 보여줍니다

     파일을 하나씩 복사하며 본편 패치(CULDCEPT.DAT)는 절대 건드리지 않습니다.

  옵션

     python install_patch.py --skip-dlc     DLC 없이 본편만
     python install_patch.py --remove-dlc   DLC 오버레이만 제거
     python install_patch.py --azahar "경로"  Azahar 폴더 직접 지정


■ 폴더가 두 개인 건 정상입니다 (대소문자 문제가 아닙니다)

  load\mods 안에 아래 두 폴더가 같이 있는 게 맞습니다.

      00040000000F5700     <- 본편 게임
      0004008c000f5700     <- DLC

  비슷해 보이지만 가운데가 다릅니다.

      0004 0000 000F5700   본편
      0004 008c 000f5700   DLC
           ^^^^            여기가 다릅니다

  'F' 의 대소문자 때문에 폴더가 둘로 갈라진 것이 아닙니다. 윈도우는 폴더 이름의
  대소문자를 구분하지 않으므로 그런 일은 생기지 않습니다. 서로 다른 타이틀 ID 라
  두 개인 것이고, 둘 다 있어야 정상입니다.


■ 예전 패치를 쓰다가 파일이 엉킨 경우 (이슈 #14 / #15)

  DLC 파일이 본편 폴더 안에 들어가 있으면 문제가 생깁니다. 구체적으로

      load\mods\00040000000F5700\romfs\ContentInfoArchive_JPN_ja.bin
      load\mods\00040000000F5700\romfs_ext\*.ips

  이 있으면, Azahar 가 본편 RomFS 에서 존재하지 않는 파일을 수만 번 찾고
  카탈로그를 반복 접근하다 프리징으로 이어집니다.

  설치.cmd 가 이 파일들을 자동으로 치워줍니다. 본편 패치는 그대로 둡니다.

  예전 배포본의 load 폴더를 통째로 옮기다가 본편 폴더가 통째로 사라진 경우에는,
  위 1) 을 다시 해 CULDCEPT.DAT 을 만들어 넣어야 합니다. 그 파일은 저작권상
  배포할 수 없어 패키지에 넣지 못합니다.


■ 수동 설치 (설치기를 쓰지 않을 때)

  dlc_overlay\0004008c000f5700 폴더의 내용을

      <Azahar 사용자 폴더>\load\mods\0004008c000f5700\

  안에 넣습니다. 최종적으로 아래가 있어야 합니다.

      load\mods\00040000000F5700\romfs\CULDCEPT.DAT        (본편)
      load\mods\0004008c000f5700\romfs\ContentInfoArchive_JPN_ja.bin
      load\mods\0004008c000f5700\romfs_ext\*.ips           (108개)

  DLC 를 갖고 있지 않아도 본편 패치는 정상 동작합니다.


■ 확인

  verify_install.cmd 를 더블클릭하면 설치 상태를 검사합니다.
  게임을 완전히 종료한 뒤 새로 부팅하고, 세이브 스테이트를 바로 불러오지 마세요.
  (로그 기반 경고는 껐다 켜기 전 기록일 수 있어, 재부팅 후 다시 검사해야 합니다.)
